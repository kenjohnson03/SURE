# SURE Releases

This repository is the binary update channel for SURE.

It intentionally contains no application source code, internal documentation, branding source, team configuration, evidence, or signing private keys.

Install SURE from the latest release:

1. Download `SURE-Windows-x64-Installer.zip`.
2. Extract the ZIP.
3. Run `Install-SURE.cmd`.

The installer registers `SURE.appinstaller`, and Windows checks this repository's latest stable release for future updates.
